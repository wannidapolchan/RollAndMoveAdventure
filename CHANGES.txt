Roll-and-Move Adventure - Changes From the Design Document
Wannida Polchan, CS 583

NEW FEATURES (not in the one-pager)
- Snake escape: when a player lands on a snake and has at least 1 coin, they can
  pay 1 coin to escape instead of sliding down (Y / N keys or buttons). This makes
  coins matter for more than just the Lucky Die.
- Computer opponent: the title screen has "1 Player vs Computer" as well as
  "2 Players". The computer picks dice and decides on snake escapes on its own.
  This was a stretch goal in the one-pager.
- Character select screen: each player picks an animal (Kenney Animal Pack).
  A character that is already taken is grayed out, and the computer picks a
  random free one. The list of characters can be changed in the Inspector.
- Players start with 1 coin, so the Lucky Die and the snake escape can be used
  from the start of the game.
- New Life Event cards: "Four-Leaf Clover" (next Lucky Die roll is free),
  "Birthday Party" (take 1 coin from each player), "Rainy Day" (everyone moves
  back 2) and "Shortcut" (move forward 3). There are 10 cards in total. The deck
  is shuffled, so a card does not repeat until all cards have been drawn.
- How to Play screen on the title screen.
- Win screen shows stats: ladders climbed, snakes hit, snakes escaped, coins left
  and total turns.
- Extra feedback: "Player 1's Turn" banner, floating text (+2 coins, Ouch!, ...),
  coin shower, sparkles, confetti, camera shake on snakes, and a character that
  bounces on its turn and celebrates when it wins.
- Inspector settings: ladders, snakes, coin tiles, event tiles, characters,
  colors, starting coins and move speed can all be changed on the Game object
  without editing code.
- "Build Board in Scene" button: builds the board as real objects in the scene,
  so it can be seen and adjusted without pressing Play.

CHANGES
- The player setup screen became a game mode choice plus a character select
  screen. Players do not type names, which kept the scope small.
- No background music. The assignment asks to hear the game sounds clearly, so
  the game uses sound effects only.
- Board layout: 3 ladders (2 to 14, 8 to 20, 22 to 27), 3 snakes (18 to 4,
  24 to 12, 28 to 16), 4 coin tiles (5, 10, 23, 26) and 5 Life Event tiles
  (3, 9, 19, 25, 29).
- "START HERE" and "FINISH" labels are placed beside the board.
- The side panel shows both players, the die choice, the last roll and the
  Roll button, with the current message at the bottom.
- If a roll goes past the Finish tile, the character stops on Finish and wins.
- Moves caused by a Life Event card (like "Shortcut") do not trigger the tile the
  character lands on. Only the first tile's effect happens, as planned.
- The pause menu also has Restart and Main Menu, not just Resume.
- Extra keys: Y / N for the snake choice, H for How to Play, Left / Right and
  Space on the character select screen, R and M in the pause menu.

NOT ADDED
- The "Swap" face on the Lucky Die (stretch goal). The Lucky Die faces are
  -2, 0, 3, 5, 8 and 10.

ART AND SOUND
- Kenney asset packs (CC0, kenney.nl):
  - UI Pack: board tiles and buttons
  - Board Game Pack: white dice, and the cards used for Life Events
  - Animal Pack: player characters
- Made from Kenney art with Tools/make_from_kenney.py: the Lucky Die faces
  (red Kenney die with numbers added) and the Life Event tile icon (blue card
  with a "?").
- Made with the Python scripts in the Tools folder: wood background, snakes,
  ladder, coin, panels, finish flag and small effects (sparkles, confetti).
- All sound effects were made with Tools/gen_sfx.py.
